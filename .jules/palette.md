## 2025-03-22 - Toggle Button Accessibility
**Learning:** For custom tab or toggle button groups (like Scan Type or Report Format selectors), visual classes like `bg-teal-600 text-white` are not enough for screen readers. Using `role="group"` on the container with a proper label (`aria-labelledby` or `aria-label`), and setting `aria-pressed={isActive}` on the buttons is critical for conveying the current selection state to assistive technologies. Keyboard focus styles (like `focus-visible:ring-2`) should also be applied to these buttons since they are interactive elements.
**Action:** Always verify that custom UI controls that act as radio buttons or tabs have appropriate ARIA roles (`group`, `radiogroup`, or `tablist`) and state attributes (`aria-pressed`, `aria-checked`, or `aria-selected`), along with clear visual focus indicators.

## 2025-03-23 - Skip to Main Content Link Programmatic Focus
**Learning:** When implementing a 'Skip to main content' link in a React SPA, ensuring the target container (e.g., `<main>`) has `tabIndex={-1}` is required to allow it to receive programmatic focus. Using `outline-none` on the target container is also essential to prevent an unwanted default focus ring from appearing around the entire main content area when it is skipped to. For the link itself, using `sr-only focus:not-sr-only focus:absolute` along with a sufficiently high z-index (e.g., `focus:z-[100]`) ensures it appears above sticky or fixed elements (like navigation bars) when it receives keyboard focus.
**Action:** When adding a "Skip to content" link, always verify the target anchor container has `tabIndex={-1}` and `outline-none` to allow programmatic focus without visual degradation, and use a high `z-index` for the skip link when focused to bypass sticky headers.
