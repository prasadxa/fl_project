## 2024-05-22 - [LaTeX Injection in Diagnostic Reports]
**Vulnerability:** The LaTeX diagnostic report generation (`backend/latex_report.py`) used unescaped user input (like patient names and IDs) directly in a string-interpolated `.tex` file template. This allowed LaTeX injection, meaning an attacker could craft inputs containing LaTeX special characters (e.g., `\} \input{/etc/passwd}`) to potentially execute arbitrary commands, read sensitive files from the server, or cause denial of service during `pdflatex` compilation.
**Learning:** LaTeX compilation (`pdflatex`) is a complex engine that processes macros and commands. Treating a `.tex` file simply as a string template without proper escaping of LaTeX-specific special characters (`\`, `{`, `}`, `$`, `&`, `%`, `#`, `_`, `^`, `~`) is highly insecure when the inputs are user-controlled.
**Prevention:** Always sanitize/escape user inputs before inserting them into a `.tex` file template, or use a dedicated templating engine that automatically handles LaTeX escaping.
