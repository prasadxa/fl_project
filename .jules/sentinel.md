## 2024-03-22 - [FastAPI Path Parameter URL-Decoding Bug]
**Vulnerability:** Path traversal in a catch-all route that serves static files using FastAPI path parameters.
**Learning:** FastAPI's '{path:path}' definition decodes URL-encoded payloads like '%2e%2e%2f' after Starlette's initial sanitization, bypassing standard sanitizations and directly feeding dangerous input to 'pathlib.Path'.
**Prevention:** Always verify paths mathematically using 'candidate.resolve().relative_to(base_dir.resolve())' instead of trusting the input when generating file paths.
## 2024-10-27 - Securing Admin Endpoints with HTTPBasic
**Vulnerability:** Admin endpoints exposing sensitive patient feedback, sessions, and statistics were publicly accessible without any authentication. This allowed unauthorized data exfiltration. Additionally, default credentials should not be hardcoded or fallback. The frontend was also incorrectly using `window.open` for file downloads, which does not support custom headers like `Authorization`.
**Learning:** `secrets.compare_digest` should be used instead of standard string equality when verifying credentials in Python to prevent timing attacks. In React, file downloads protected by custom authentication headers must use `fetch()` to retrieve a blob, followed by programmatically triggering the download using `window.URL.createObjectURL()`.
**Prevention:** Always secure all administrative endpoints by default with robust authentication, ensuring sensitive secrets are checked safely using constant-time comparison operations. Avoid `window.open` for authenticated endpoints and rely on native `fetch` wrappers that append necessary authorization headers.
