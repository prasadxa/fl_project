## 2025-03-05 - Fix Path Traversal in Frontend Static File Serving
**Vulnerability:** A critical path traversal vulnerability was found in the catch-all route (`/{full_path:path}`) in `backend/api.py`. The route appended user input `full_path` directly to the `FRONTEND_DIR` base path using `FRONTEND_DIR / full_path` without resolving and validating that the resulting path stayed within `FRONTEND_DIR`. This allowed attackers to access arbitrary files on the system using `../` (e.g. `/%2e%2e%2fetc%2fpasswd`).
**Learning:** `pathlib`'s `/` operator concatenates paths but does not automatically resolve or sanitize `..`. It is not sufficient to just check `is_file()`. You must explicitly resolve the path and verify it belongs to the intended base directory to prevent escaping the directory boundary.
**Prevention:** Always validate that resolved file paths are relative to their intended base directory. Use `candidate.resolve().is_relative_to(BASE_DIR.resolve())` before accessing or serving any file based on user input.
