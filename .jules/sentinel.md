## 2025-02-28 - FastAPI `{path:path}` Parameter Traversal
**Vulnerability:** A path traversal vulnerability was present in `backend/api.py` when serving static frontend files using the catch-all route `@app.get("/{full_path:path}")`. The `full_path` string was directly concatenated with `FRONTEND_DIR` to construct the file path without resolving and verifying the path boundary.
**Learning:** In FastAPI, path parameters defined as `{path:path}` decode URL-encoded traversal payloads (like `%2e%2e%2f` to `../`) *after* Starlette's initial path sanitization. Therefore, payloads that bypass Starlette's checks can be reassembled into traversal sequences when passed to the path operation function.
**Prevention:** Always securely verify path parameters intended to be used as file paths. Resolve the constructed path using `pathlib.Path.resolve()` and ensure it resides within the intended base directory using `candidate.relative_to(base_dir.resolve())`. Catch `ValueError` to handle boundary violations.
