## 2024-03-22 - [FastAPI Path Parameter URL-Decoding Bug]
**Vulnerability:** Path traversal in a catch-all route that serves static files using FastAPI path parameters.
**Learning:** FastAPI's '{path:path}' definition decodes URL-encoded payloads like '%2e%2e%2f' after Starlette's initial sanitization, bypassing standard sanitizations and directly feeding dangerous input to 'pathlib.Path'.
**Prevention:** Always verify paths mathematically using 'candidate.resolve().relative_to(base_dir.resolve())' instead of trusting the input when generating file paths.
## 2025-02-28 - Missing Authentication on Admin Endpoints
**Vulnerability:** The backend admin endpoints (`/api/admin/*`) used to view sensitive feedback logs, export the database, and see application stats were completely unprotected and open to anyone.
**Learning:** In FastAPI, it's easy to add new routes and forget to apply dependencies. Security must be explicitly enforced on every sensitive route. Also, when writing tests to ensure a dependency throws an internal 500 error (e.g., due to unconfigured server secrets), the test request *must* contain an `Authorization` header with dummy credentials; otherwise, FastAPI's `HTTPBasic` mechanism will short-circuit and return a 401 Unauthorized before ever executing the custom dependency logic.
**Prevention:** Apply authentication dependencies systematically (e.g., at the router level `dependencies=[Depends(verify_admin)]` rather than per-route) to prevent accidental omissions when adding new endpoints. Ensure `os.getenv` calls for secrets fail securely (500) if missing, rather than using weak defaults. Always use `secrets.compare_digest` for timing-attack resistance.
